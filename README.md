# KRN Marketing Board

Live operations dashboard for Katrina Ridout Nutrition's automated marketing system.

Built by Anthony Ridout. Fourteen scheduled Claude agents (content, SEO, ads, leads, comments, approvals, daily brief) plus a Make.com content pipeline (WordPress publisher → Veo reel → overlay render → vision QA → Buffer) run the practice's marketing without hands-on time. This board is the single view of what ran, what published, what needs a human.

Static page, no build step. Open `index.html` or view it on GitHub Pages.
